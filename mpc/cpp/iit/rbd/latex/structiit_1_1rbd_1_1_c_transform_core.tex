\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Scalar$>$\newline
struct iit\+::rbd\+::\+CTransform\+Core$<$ Scalar $>$}
A compact type that can act as different representations of a coordinate transform.

An instance contains the minimum amount of data to encode a coordinate transform for homogeneous coordinates and spatial vectors (both motion and force)\+: a rotation matrix and a translation vector.

Different member functions implement the actual coordinate transformation for the different representations.
