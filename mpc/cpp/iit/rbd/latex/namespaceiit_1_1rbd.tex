\doxysubsection{Detailed Description}
This namespace contains some basic types and functions related to spatial vectors and Rigid Body Dynamics (RBD).

This code has been developed to provide basic types and general utilities to be used in turn by the C++ classes generated by the Robotics Code Generator (Rob\+Co\+Gen). That is, the code is just meant to be a common, generic facility for all the robot-\/specific code that Rob\+Co\+Gen can generate.

In other words, the primary target of the {\ttfamily iit\+\_\+rbd} library is not to provide a comprehensive object-\/oriented implementation of concepts of rigid-\/body dynamics and spatial vectors, for end-\/user applications. Some of such concepts do appear in this software, although the implementation is relatively simple. However, the library may very well be used in custom code that needs e.\+g. a type for spatial vectors or for the spatial 6x6 inertia tensor.
