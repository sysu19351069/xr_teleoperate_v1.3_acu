\doxysubsection{Detailed Description}
Main, basic data types and functions

All the types are templated on the Scalar type. There are two ways of defining a complete type in client code. For individual types one can use something like this\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keyword}{typedef}\ iit::rbd::Velocity<\ float\ >\ myVelocity;}

\end{DoxyCode}


An alternative, maybe neater in the case of multiple types, is the following\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keyword}{typedef}\ \textcolor{keywordtype}{float}\ Scalar;}
\DoxyCodeLine{\textcolor{keyword}{typedef}\ iit::rbd::Core<\ Scalar\ >\ mycore;}
\DoxyCodeLine{}
\DoxyCodeLine{\textcolor{keyword}{using\ }Matrix33\ =\ mycore::Matrix33;}
\DoxyCodeLine{\textcolor{keyword}{using\ }Vector3\ \ =\ mycore::Vector3;}
\DoxyCodeLine{\textcolor{keyword}{using\ }Velocity\ =\ mycore::VelocityVector;}
\DoxyCodeLine{\textcolor{comment}{//\ etc.}}

\end{DoxyCode}
